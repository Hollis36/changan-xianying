# 长安显影

在点与点之间，看见长安。

西安钟楼、大雁塔、永宁门的点云交互展览。珠光白背景、三首原创题诗、构件分层与建筑数学关系。

## 本地制作

需要 Node.js 20 或更新版本。

```sh
npm ci
npm test
npm run build
python3 -m http.server 4185 --directory docs
```

打开 http://localhost:4185/ 。`site/`为展示页源文件，`src/`为交互原型源码，`docs/`为GitHub Pages发布目录。修改后先构建，再提交并推送main；Pages发布main分支的docs目录。

## 在线播放

主页默认使用 Bilibili 官方外链播放器，稿件 BV1hm4p6XErc（上传 3840×2160、30fps、126 秒原片）。关闭自动播放和弹幕，保留全屏、平台观看链接及原片下载。实际画质、转码进度、登录要求和地区可用性由 Bilibili 决定，上传 4K 不等于所有访客都能在嵌入页选择 4K。接入遵循 https://player.bilibili.com/ 的公开参数，不提取临时媒体直链、不保存账号 Cookie。

“备用播放”打开独立的 direct.html，继续提供原有原生播放器、4K/1080P 切换和网络检测。主页不加载这套控制器，也不同时预加载 GitHub MP4；第三方播放器不可用时仍可手动选择备用播放或下载原片。两个播放器之间不自动同步播放进度。

## 影像与备用播放

主片126秒、3840×2160、30fps，建筑缓慢旋转、钟楼构件展开合拢、点云散聚与塔层显现。4K原片在Release中，备用播放器默认自动画质，优先在线播放保留3840×2160、30fps的4K网络优化副本（H.264，约235MB，平均总码率约15Mbps；原片约633MB、40Mbps），持续缓冲8秒时自动切换至1080P并显示提示；手动选择4K后不会自动降级。切换时保留播放位置。打开备用播放页即通过原生视频播放器请求预加载当前4K视频内容（preload=auto），不自动播放，也不另外创建下载任务；切换画质仍复用同一个播放器。浏览器会根据网络、省流量设置和自身策略决定缓存量，不保证整片下载完成或离线可用。MP4索引位于文件头，支持边下边播。4K网络版经过有损压缩，细颗粒会略有变化；下载按钮仍指向原片。原片保持独立，不混入Git历史。

## 备用播放的自动选线

打开备用播放页后，播放器观察现有 4K 缓冲约 8 秒，同时查询浏览器的解码能力，并用每条最多 512KiB、4 秒超时的小片段比较 Pages 与 GitHub Raw 两个现有 1080P 地址。自动模式下，4K 缓冲不足或设备评估不适合时改用 1080P，并选择本次测得加载更快的地址。真实加载失败后，可尝试另一条已测通的 1080P 线路；不循环重试。切换保留播放位置和播放意图，手动画质不被自动降级。

“播放状态”默认收起，展开可查看当前线路、设备评估、两次取样耗时，并重新检测。手动切换画质会取消旧测速；一分钟内复用完成的结果，主动重新检测则重新取样。省流量模式跳过测速并优先 1080P。检测在访客浏览器中完成，不查询位置或上传测速结果。

这只是现有视频地址的取样选择，不能改变运营商线路，也不保证任何地区、网络或设备都能无卡顿播放。4K 当前只有一条来源，1080P 两条来源都属于 GitHub；如两条都无法访问，仍需要独立的视频分发服务。本地 Python 静态服务器不支持 Range，因此本地的站点线路取样会显示未测通，线上 Pages 支持。

## 表达边界与来源

模型为程序化艺术重构，不是现场扫描、实测测绘或历史复原。构件与几何关系用于讲解，不构成结构分析结论。三首题诗、代码与制作过程包含AI辅助；不冒称古人诗作或完全手工作品。研究来源可在交互展览里展开，作品说明位于docs/assets/project.pdf。
